# Smoking & Health Analysis Dashboard

## Project Overview
This project focuses on analyzing the relationship between smoking habits and various health indicators using Microsoft Power BI.

The dashboard provides insights into patient demographics, smoking status, smoking exposure duration, diagnosed organ categories, health conditions, blood pressure risk categories, and cholesterol levels.

## Objectives
- Analyze patient distribution by smoking status.
- Examine average daily cigarette consumption.
- Explore health conditions across diagnosed organ categories.
- Analyze cholesterol levels across blood pressure risk categories.
- Identify current smokers across different age groups.
- Examine health conditions across smoking exposure levels.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel
- CSV Dataset

## Dataset Overview
The dataset contains 10,000 patient records and 15 original columns, including:

- Patient ID
- Age and Gender
- Region
- Diagnosis Date
- Smoking Status
- Cigarettes Per Day
- Years Smoking
- Diagnosed Organ
- Health Condition
- Total Cholesterol
- Systolic and Diastolic Blood Pressure
- BMI
- Resting Heart Rate

The original dataset is not included in this repository.

## Data Preparation
- Checked column data types.
- Verified data quality and missing values.
- Checked for duplicate patient IDs.
- Applied Power Query transformations.
- Created calculated columns and measures using DAX.

## Key Performance Indicators (KPIs)
- Total Patients: 10,000
- Current Smokers: 3,015
- Patients with Recorded Organ Condition: 7,227
- Patients with Recorded Health Condition: 5,772

## Dashboard Features

### Page 1 – Patient Health Overview
- Patient distribution by smoking status.
- Average cigarettes consumed per day by smoking status.
- Average cholesterol by blood pressure risk category.
- Interactive filters for Gender, Region, and Age Group.

### Page 2 – Smoking & Health Demographics
- Current smokers across age groups.
- Health conditions by diagnosed organ.
- Health conditions by smoking exposure level.
- Interactive filters for Gender, Region, and Smoking Status.

## DAX Calculations
Created DAX measures for:
- Total Patients

- Patients with Recorded Organ
- Patients with Recorded Condition
- Average Cigarettes Per Day

Created calculated columns for:
- Age Group
- BP Risk Category
- Smoking Exposure Level

## Disclaimer
This project is intended for educational and exploratory data analysis purposes only. The BP risk categories and other health indicators are simplified analytical classifications and should not be interpreted as medical diagnoses or evidence of causation.
